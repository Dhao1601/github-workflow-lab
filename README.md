# GitHub Workflow Lab

Repo thực hành nhánh, pull request và merge trên GitHub.

## Quy trình thay đổi

1. Tạo nhánh riêng cho một thay đổi nhỏ.
2. Chỉnh tài liệu hoặc mã nguồn và kiểm tra diff.
3. Mở pull request, mô tả mục đích và cách kiểm tra.
4. Với dự án thực tế, nhờ cộng tác viên review trước khi merge.
5. Merge sau khi kiểm tra xong và xóa nhánh đã hoàn thành.

Repo này dùng để thực hành; không chứa mã ứng dụng production.
